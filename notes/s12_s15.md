### 2. MCP server `/ai-mcp` — 3ステップ

**JP**
> ⏎ Claude Code、Gemini CLI、Copilot……AI エージェントでコードを書く人、多いと思います。
> ⏎ Dart と Flutter には公式の MCP server があります。`dart mcp-server` です。AI rules や agent skills も公式に用意されています。
> ⏎ これで何ができるかというと、エージェントが「動いているアプリ」を触れるんです。analyze を回す、Hot Reload する、Widget ツリーを見る、実行時エラーを読む、pub.dev でパッケージを探す。
> つまり、書いて終わりじゃなくて、実行して、見て、直せる。

*下の6つのチップを指でなぞる。*

### 3. なぜ相性がいいのか `/ai-why` — 5ステップ

**JP**
> ⏎ 宣言的 UI。UI がそのままコードで、ツリー構造なので LLM が得意な形です。
> ⏎ 1つのコードベース。同じ画面を iOS 用と Android 用に2回生成させなくていい。
> ⏎ 型と analyzer。間違いがすぐに分かるので、AI に速くフィードバックを返せる。
> ⏎ Hot Reload。1秒で反映されるループを、エージェントも同じ速さで回せる。
> ⏎ そしてテストが書きやすい。AI の変更を、テストで確かめてから受け入れられます。

### 5. 私の個人開発フロー：まず Web で作る `/ai-web-first` — 1ステップ 🖱

> *（自動再生）* まず Claude に「カフェの予約アプリを作って」と頼みます。
> Claude は Web アプリとして実装して、自分のサンドボックスの中で起動して、スクリーンショットを見せてくれます。

### 11. テストを目で見る `/q-runner` — 1ステップ 🖱

**JP**
> このテストが1行ずつ何をしているか、見てみましょう。「テスト実行」。
> pumpWidget でアプリが描画されて、「0」を探す、ある。「1」を探す、ない。
> tap で tester が指になってボタンを押して、pump で1フレーム進めると、1 になる。全部緑です。
> では、バグを入れてみます。+1 のつもりが +2 になるバグ。……最後の expect で赤くなりました。「1 が見つからない」。

*🖱 1回目はそのまま実行 → 2回目はスイッチを ON にして実行。*

### 12. Golden テスト `/q-golden` — 3ステップ

**JP**

> ただしフォントの描画は OS で少し違うので、CI では同じ OS で回すのが鉄則です。

### 17. A2UI とは `/g-a2ui` — 3ステップ

**JP**
> ⏎ ユーザーが話しかけると、エージェントが「どんな UI がいいか」を考えます。
> ⏎ その UI を A2UI という JSON で送ります。ここがポイントで、送るのはコードではなくデータ。クライアントのレンダラーが、手元のカタログにある部品だけを使って組み立てます。だから安全。
> ⏎ ユーザーがタップすると、それが userAction としてエージェントに戻り、UI が更新される。ストリーミングで少しずつ届き、データモデルにバインドもできます。レンダラーは Flutter のほか Lit や Angular もあります。

---

### 18. A2UI の JSON `/g-json` — 4ステップ

**JP**
> ⏎ 部品は id でつながったフラットなリストです。
> ⏎ component はカタログの名前。
> ⏎ path でデータモデルにバインド。
> ⏎ action はエージェントに返るイベント。
> 形式は v0.9 をもとに簡略化したイメージです。

---

### 19. なぜ Flutter が最初なのか `/g-why-flutter` — 5ステップ

**JP**
> なぜ Flutter が A2UI の最初のフレームワークになったのか。
> ⏎ Widget がそのまま部品カタログになる。
> ⏎ 宣言的な Widget ツリーと、JSON の部品ツリーが同じ形をしている。
> ⏎ 自前で描くので、1つのレンダラーで6つのプラットフォームが同じ見た目になる。
> ⏎ 部品ごとにスキーマを持てるので、LLM の出力を検証できる。
> ⏎ そして、GenUI SDK は A2A チームや Google Labs の Opal チームと一緒に、A2UI を前提に作られました。A2UI と一緒に生まれた、最初期のレンダラーです。

---

### 20. GenUI SDK `/g-sdk` — 3ステップ

**JP**
> ⏎ 使い方は3ステップ。自分の Widget を、スキーマと一緒にカタログに登録。
> ⏎ エージェントとつなぐ。Gemini でも、A2A のサーバーでも。
> ⏎ あとは Surface を置けば、生成された UI がそこに描かれます。
> API はバージョンごとにまだ変わっているので、これはイメージです。最新は公式ドキュメントで。
